# 智慧园区

基于 React、TypeScript 和 Vite 的智慧园区管理后台，面向单园区日常运营场景，提供企业、人员、访客、车辆、工单、设备及系统管理功能。

项目是可交互的前端演示系统，所有业务接口由浏览器端 MSW 模拟，不依赖真实后端，也不连接数据库、门禁、停车设备或第三方平台。业务修改保存在当前浏览器中，可用于产品演示、交互验证和前端开发参考。登录、角色权限及数据范围校验均为模拟实现，不作为生产级安全方案。

## 技术栈

| 技术                           | 用途                |
|------------------------------|-------------------|
| React、TypeScript、Vite        | 组件开发、类型检查、开发服务及构建 |
| Ant Design、@ant-design/icons | 交互组件、布局和图标        |
| React Router                 | 页面路由、访问校验和页面按需加载  |
| Zustand                      | 认证、当前用户和菜单状态      |
| Axios                        | HTTP 请求、响应解包及异常处理 |
| MSW                          | 浏览器端 HTTP 接口模拟    |
| ECharts                      | 运营指标图表            |
| Day.js                       | 日期处理及中文日期展示       |
| write-excel-file             | 已选业务记录的 Excel 导出  |
| SCSS                         | 全局及组件视觉样式         |
| Oxlint、ESLint、Prettier       | 静态检查及格式化          |

## 环境准备

- Node.js `>=24.18.0`、pnpm `>=11.13.0`。
- 包管理器：`pnpm@11.13.0`。

## 演示账号

| 角色     | 账号           | 初始密码             | 初始数据范围 |
|--------|--------------|------------------|--------|
| 超级管理员  | `admin`      | `Admin@123`      | 全部数据   |
| 园区运营人员 | `operator`   | `Operator@123`   | 当前园区   |
| 企业用户   | `enterprise` | `Enterprise@123` | 所属企业   |

- 超级管理员可体验全部业务、用户与角色管理、操作日志和 Mock 数据管理。
- 园区运营人员主要维护业务档案、审批访客预约并处理工单。
- 企业用户主要查看所属企业数据、创建访客预约和工单，并确认工单处理结果。

> 模拟会话有效期为两小时。

## 功能概览

| 模块        | 主要能力                         |
|-----------|------------------------------|
| 运营总览      | 核心指标、趋势图表、今日任务和设备状态          |
| 园区档案      | 园区信息查看与编辑、楼宇空间树和空间明细         |
| 企业管理      | 企业筛选、新增、编辑、启停及详情查看           |
| 人员管理      | 人员筛选、新增、编辑、启停及详情查看           |
| 访客管理      | 预约创建、审批、驳回、签到、签出、取消及到访记录     |
| 车辆与停车     | 车辆档案维护、启停及停车记录查询             |
| 工单中心      | 创建、受理分派、处理、确认评价、取消、重新打开及流程记录 |
| 设备管理      | 设备档案维护、状态调整及状态变化记录           |
| 用户管理      | 账号维护、启停、重置密码及分配角色            |
| 角色管理      | 自定义角色新增、编辑、删除及页面和操作权限配置      |
| 操作日志      | 日志筛选、操作结果及请求详情查看             |
| Mock 数据管理 | 响应延迟、模块异常模拟及恢复初始数据           |
| 个人中心      | 当前账号信息、姓名修改及密码修改             |

企业、车辆、设备列表支持跨页勾选并导出已选记录为 `.xlsx` 文件。

## 环境变量

| 变量                  | 默认或仓库配置        | 用途           |
|---------------------|----------------|--------------|
| `VITE_ENABLE_MSW`   | 开发和生产均为 `true` | 开发和生产都启用 MSW |
| `VITE_API_BASE_URL` | 未配置时为 `/api`   | Axios 请求基础地址 |
